# 🎓 AI-Powered Campus Intelligence Dashboard

### Academic Performance & Placement Analytics

## 📌 Project Overview

The **AI-Powered Campus Intelligence Dashboard** is a data analytics project designed to analyze student academic performance, attendance, assignment submissions, extracurricular participation, and placement outcomes.

The project uses Python, SQL, Power BI, and machine learning to transform raw student data into meaningful insights, helping educational institutions monitor student performance, identify at-risk students, and understand placement trends.

## 🎯 Project Objectives

- Analyze student academic performance and semester-wise trends.
- Identify patterns between attendance, internal marks, and assignment submissions.
- Evaluate placement outcomes and employability trends.
- Develop interactive dashboards to monitor key academic and placement KPIs.
- Explore machine learning techniques to identify students who may require academic support.

## 🛠️ Tools & Technologies

- **Python:** Data analysis and preprocessing
- **Pandas & NumPy:** Data cleaning and transformation
- **SQL:** Data extraction, joins, aggregations, and querying
- **Power BI:** Interactive dashboards and KPI visualization
- **Matplotlib & Seaborn:** Exploratory data analysis and visualization
- **Scikit-learn:** Machine learning experiments
- **Git & GitHub:** Version control and project documentation

## 📊 Key Performance Indicators (KPIs)

### Academic Analytics
- Average student marks
- Attendance percentage
- Assignment submission rate
- Semester-wise academic performance
- Students requiring academic support

### Placement Analytics
- Overall placement rate
- Number of students placed
- Average placement package, where data is available
- Department-wise placement performance
- Relationship between academic performance and placement outcomes

## 🔍 Project Workflow

1. **Data Collection:** Gather student academic, attendance, assignment, and placement datasets.
2. **Data Cleaning:** Handle missing values, duplicates, inconsistent formats, and invalid records using Python.
3. **Data Analysis:** Use Pandas and SQL to explore academic performance and placement patterns.
4. **Exploratory Data Analysis:** Visualize trends, distributions, and relationships among student metrics.
5. **Machine Learning:** Experiment with classification models to explore at-risk student identification or placement prediction, subject to suitable data availability.
6. **Dashboard Development:** Build interactive Power BI reports with KPIs, filters, and charts.
7. **Insights & Recommendations:** Translate analytical findings into actionable recommendations for academic monitoring and placement planning.

## 💡 Expected Business Value

- Helps institutions monitor academic progress.
- Supports early identification of students who may need additional assistance.
- Highlights academic and placement trends across departments and semesters.
- Enables data-driven planning for academic interventions and placement preparation.
- Presents key information in a centralized, interactive dashboard.

## 🚀 How to Run

1. Clone or download this repository.
2. Install the required Python libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebooks using Jupyter Notebook or Google Colab.
4. Place the raw datasets in the `data/raw/` folder.
5. Run the notebooks sequentially to clean and analyze the data.
6. Execute the SQL scripts in your selected database.
7. Open the Power BI `.pbix` file to explore the dashboard, or recreate the report using the processed datasets.
